# Milestone v2.0: Pattern Analysis

**Status:** ✅ SHIPPED 2026-06-11
**Phases:** 4–6
**Total Plans:** 12

## Overview

Pattern Analysis release. Added three major analysis modules: behavioral pattern analysis (time-bucketed sliding windows with weekday/weekend segmentation), overnight pattern analysis (10pm-6am glucose window), and anomaly detection (PISA-filtered outlier detection with severity classification and weekly summaries). All features accessible via library API, CLI flags, and web dashboard.

## Milestone Summary

**Key Decisions:**
- CV computed as std-of-daily-overnight-means / mean * 100 — cross-night variability, not intra-night
- night_date maps post-midnight readings back one day — ensures overnight readings belong to the evening they started
- Excursions aggregated to night-level counts — avoids clinical alert framing
- baselines.height==0 returns insufficient_data=False — uniform data has no variance but analysis ran successfully
- PISA loop advancement: i=nadir_idx+1 after flagging — correct loop progression past pressure artifacts

**Issues Resolved:**
- PISA loop advancement bug (WR-01) — fixed in code review
- strftime portability (IN-01) — switched to f-string day formatting
- Deterministic period sort (IN-02) — fixed sort key
- std_g None guard, post-filter insufficient_data check, MIN_NIGHTS_FOR_SPLIT=3, night_date-based day_type

**Technical Debt:**
- Anomaly detection and suggestions removed from web UI in v3.0 quick tasks (feature devalued by simplification pass)
