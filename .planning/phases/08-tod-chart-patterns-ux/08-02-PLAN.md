<objective>
Redesign behavioral_patterns.html to replace the `<details>`/`<summary>` accordion with inline
two-dimensional rows. Every row simultaneously shows: time label, consistency badge, range status
badge (Below/In/Above Range), avg glucose, and weekday/weekend split — all visible on first render.
A density filter limits rows to non-overlapping bucket boundaries.

Purpose: Users currently have to click "Show score" on each row to see variability details and
never see range status at all. After this redesign they can scan all time windows at a glance.

Output: Redesigned behavioral_patterns.html with inline badges, no accordion, density filter
applied, and wellness disclaimer unchanged.
</objective>
