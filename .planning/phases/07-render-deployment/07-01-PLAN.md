# Plan 07-01: Render Deployment

## Goal

Make the web app deployable on Render with zero manual dashboard configuration.
Four changes are required:

1. **Remove `weasyprint`** from `pyproject.toml` — it is not imported anywhere in
   the codebase (only referenced in a CSS comment) but requires Cairo/GTK system
   libraries that are absent on Render's build image.

2. **Create `render.yaml`** — infrastructure-as-code config that tells Render the
   Python version, build command, start command, and the `PYTHONPATH=src` env var
   needed to import the `web` package.

3. **Fix CORS** in `src/web/app.py` — replace the hardcoded `allow_origins=["*"]`
   with an env-var-driven list (`ALLOWED_ORIGINS`), defaulting to `["*"]` only when
   the var is unset (dev fallback). This lets Render's env var be set to the
   deployed URL without touching code.

4. **Verify `web` module is importable** under `PYTHONPATH=src` — confirm the
   start command `uvicorn web.app:app` works with that path set.

### Task 2: Create render.yaml

Create at repo root:

```yaml
services:
  - type: web
    name: cgm-insights
    runtime: python
    buildCommand: pip install -e .
    startCommand: uvicorn web.app:app --host 0.0.0.0 --port $PORT
    envVars:
      - key: PYTHONPATH
        value: src
      - key: ALLOWED_ORIGINS
        sync: false   # set manually in Render dashboard to https://<your-app>.onrender.com
    autoDeploy: true
```

### Task 3: Fix CORS in src/web/app.py

Replace:
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # In production, restrict this
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

With:
```python
import os

_raw_origins = os.environ.get("ALLOWED_ORIGINS", "")
_allowed_origins: list[str] = (
    [o.strip() for o in _raw_origins.split(",") if o.strip()]
    if _raw_origins
    else ["*"]
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=_allowed_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

The `import os` should be placed with the stdlib imports at the top of the file.
