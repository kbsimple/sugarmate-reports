# Plan 06-03: Web integration

## Goal

Wire anomaly detection into the web layer using the exact same four-point integration
pattern as Phase 5 overnight patterns:

1. `session.py` — add `anomaly_detection: Optional[dict]` field to `SessionData` and
   `store()` signature.
2. `upload.py` — call `analyze_anomalies(readings)` and pass the serialized dict to
   `session_store.store()`.
3. `results.py` — extract session dict, reconstruct model, call
   `generate_anomaly_suggestions()`, pass `anomaly_detection` to template context; also
   include it in the `/data` JSON endpoint.
4. New `components/anomaly_detection.html` Jinja2 template + `results.html` include.

## Files

### Modify

- path: `src/web/services/session.py`
  description: Add `anomaly_detection: Optional[dict] = field(default=None)` to SessionData dataclass and matching parameter to `SessionStore.store()`.

- path: `src/web/routes/upload.py`
  description: Import `analyze_anomalies`, call it after the overnight analysis block, store result dict in session.

- path: `src/web/routes/results.py`
  description: Import `AnomalyDetectionResult` and `generate_anomaly_suggestions`; extract, validate, and add suggestions; pass `anomaly_detection` to template context and `/data` endpoint JSON.

- path: `src/web/templates/results.html`
  description: Add `anomaly_detection.html` include block after the overnight_patterns block.

### Create

- path: `src/web/templates/components/anomaly_detection.html`
  description: Jinja2 card component rendering WeeklySummary data using DaisyUI stats/badge patterns. Parameter: `anomaly_detection` dict (may be None or have `insufficient_data=True`).

### Task 2: Create `anomaly_detection.html` component and add `results.html` include

**`src/web/templates/components/anomaly_detection.html`**

Mirror the exact structure of `overnight_patterns.html`. The component receives
`anomaly_detection` (dict or None) via `{% with %}`.

Required structure in order:

1. **File-level comment block** documenting all keys the template touches:
```jinja2
{# Anomaly Detection component.

Parameters:
  - anomaly_detection: dict from AnomalyDetectionResult.model_dump(), or None.
    Keys used: insufficient_data (bool), total_anomalies (int),
    mild_total (int), moderate_total (int), severe_total (int),
    pisa_artifacts_filtered (int), days_analyzed (int),
    weekly_summaries (list of WeeklySummary dicts).

WeeklySummary keys used: week_label (str), total_anomalies (int),
  mild_count (int), moderate_count (int), severe_count (int),
  high_count (int), low_count (int), most_affected_period (str|null).
#}
```

2. **Card wrapper**:
```html
<div class="card bg-base-100 shadow-md">
    <div class="card-body">
        <h3 class="card-title text-lg font-bold">Unusual Glucose Patterns</h3>
```

3. **Insufficient data guard** (mirrors overnight_patterns.html):
```jinja2
{% if not anomaly_detection or anomaly_detection.insufficient_data %}
<div class="alert alert-info">
    <svg xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24"
         class="stroke-current shrink-0 w-6 h-6">
        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2"
              d="M13 16h-1v-4h-1m1-4h.01M21 12a9 9 0 11-18 0 9 9 0 0118 0z"/>
    </svg>
    <div>
        <h3 class="font-bold">Not enough data for pattern baseline</h3>
        <p class="text-sm mt-1">At least 5 days of glucose data are needed to
        establish a personal baseline for unusual pattern detection.</p>
    </div>
</div>
{% else %}
```

4. **Top-level stats row** (DaisyUI `stats stats-horizontal`):
   Show total_anomalies, mild_total, moderate_total, severe_total.
   Guard each stat with `{% if value is not none %}`.
   Use `stat-title text-xs` / `stat-value text-lg` / `stat-desc` pattern.
   Label the stat-title values: "Unusual Patterns", "Mild", "Moderate", "Significant".
   Use `stat-desc` for "this period", "2–3× typical", "3–4× typical", "4×+ typical".

5. **PISA filter note** (only if `pisa_artifacts_filtered > 0`):
```jinja2
{% if anomaly_detection.pisa_artifacts_filtered > 0 %}
<p class="text-xs text-base-content/50 mt-2">
    {{ anomaly_detection.pisa_artifacts_filtered }} sensor artifact
    reading{{ "s" if anomaly_detection.pisa_artifacts_filtered != 1 else "" }}
    excluded from analysis.
</p>
{% endif %}
```

6. **Weekly summary section** (only if `weekly_summaries` is non-empty):
```jinja2
{% if anomaly_detection.weekly_summaries %}
<div class="mt-4">
    <h4 class="font-semibold text-sm mb-2">Weekly Breakdown</h4>
    {% for week in anomaly_detection.weekly_summaries %}
    <div class="flex items-start gap-3 mb-3">
        <div class="text-xs text-base-content/60 w-28 shrink-0 pt-0.5">
            {{ week.week_label }}
        </div>
        <div class="flex flex-wrap gap-1 flex-1">
            {% if week.severe_count > 0 %}
            <span class="badge badge-error badge-sm">
                {{ week.severe_count }} significant
            </span>
            {% endif %}
            {% if week.moderate_count > 0 %}
            <span class="badge badge-warning badge-sm">
                {{ week.moderate_count }} moderate
            </span>
            {% endif %}
            {% if week.mild_count > 0 %}
            <span class="badge badge-info badge-sm">
                {{ week.mild_count }} mild
            </span>
            {% endif %}
            {% if week.high_count > 0 %}
            <span class="text-xs text-base-content/60">
                {{ week.high_count }} elevated,
            </span>
            {% endif %}
            {% if week.low_count > 0 %}
            <span class="text-xs text-base-content/60">
                {{ week.low_count }} lower
            </span>
            {% endif %}
            {% if week.most_affected_period %}
            <span class="text-xs text-base-content/50">
                · most: {{ week.most_affected_period }}
            </span>
            {% endif %}
        </div>
    </div>
    {% endfor %}
</div>
{% endif %}
```

7. **Close `{% else %}` block**: `{% endif %}`

8. **Wellness disclaimer** (always visible, outside the `{% else %}` block — renders

```html
<div class="bg-base-200 rounded-lg p-2 mt-4">
    <p class="text-xs text-base-content/60">

        may reflect normal variation, activity, food, or other factors. Always

</div>
```

9. Close card: `</div></div>`
