```python
def _render_anomaly_detection(
    result,
    console: Console,
) -> None:
    """Render anomaly detection summary as Rich output.

    Shows weekly summary counts using badge-style text styling.
    Never uses "alert", "alarm", "abnormal", or clinical diagnosis terms.

    Args:
        result: AnomalyDetectionResult from analyze_anomalies().
        console: Rich Console for output.
    """
    from rich.table import Table

    console.print("\n[bold cyan]Unusual Glucose Patterns[/bold cyan]")
    console.print(
        f"[dim]({result.days_analyzed} days analyzed, "
        f"{result.total_anomalies} unusual readings detected)[/dim]\n"
    )

    if result.total_anomalies == 0:
        console.print("[dim]No unusual patterns detected in your data.[/dim]")
        return

    # Top-level severity summary
    table = Table(
        title="Unusual Pattern Summary",
        show_header=True,
        header_style="bold",
    )
    table.add_column("Tier", style="white", width=16)
    table.add_column("Count", style="cyan", width=10)
    table.add_column("Description", style="dim", width=30)

    if result.severe_total > 0:
        table.add_row(
            "[red]Significant[/red]",
            str(result.severe_total),
            "4×+ from personal baseline",
        )
    if result.moderate_total > 0:
        table.add_row(
            "[yellow]Moderate[/yellow]",
            str(result.moderate_total),
            "3–4× from personal baseline",
        )
    if result.mild_total > 0:
        table.add_row(
            "[blue]Mild[/blue]",
            str(result.mild_total),
            "2–3× from personal baseline",
        )
    console.print(table)

    # PISA note
    if result.pisa_artifacts_filtered > 0:
        console.print(
            f"\n[dim]{result.pisa_artifacts_filtered} sensor artifact "
            f"reading(s) excluded from analysis.[/dim]"
        )

    # Weekly summaries (most recent first)
    if result.weekly_summaries:
        console.print("\n[bold]Weekly Breakdown:[/bold]")
        for week in result.weekly_summaries[:4]:  # show at most 4 weeks in CLI
            parts = []
            if week.severe_count:
                parts.append(f"[red]{week.severe_count} significant[/red]")
            if week.moderate_count:
                parts.append(f"[yellow]{week.moderate_count} moderate[/yellow]")
            if week.mild_count:
                parts.append(f"[blue]{week.mild_count} mild[/blue]")
            summary = ", ".join(parts) if parts else "none"
            console.print(f"  {week.week_label}: {summary}")
```

### Task 2: Write `tests/test_analytics/test_anomaly_detection.py`

`@pytest.fixture`) that generates CGMReading objects at 5-min intervals starting from
Monday 2024-01-08 00:00:00.

**`create_readings()` factory signature**:
```python
def create_readings(
    n_days: int,
    glucose_value: float = 100.0,
    interval_minutes: int = 5,
    start_dt: datetime | None = None,
) -> list[CGMReading]:
    """Create CGMReading objects covering n_days of continuous data.

    Each day generates readings at interval_minutes cadence from 00:00 to 23:55.
    Default start is Monday 2024-01-08 00:00:00 for deterministic day_type.

    Args:
        n_days: Number of calendar days of readings to generate.
        glucose_value: Uniform glucose value for all readings (mg/dL).
        interval_minutes: Time between consecutive readings (default: 5).
        start_dt: Override start datetime (default: 2024-01-08 00:00:00).

    Returns:
        List of CGMReading with source="test".
    """
```

**Required tests (implement all 8)**:

1. **`test_empty_readings_returns_insufficient_data`**
   - Input: `[]`
   - Assert: `result.insufficient_data is True`
   - Assert: `result.total_anomalies == 0`
   - Assert: `result.weekly_summaries == []`

2. **`test_fewer_than_min_days_returns_insufficient_data`**
   - Input: `create_readings(n_days=4)` (below `MIN_DAYS_FOR_BASELINE=5`)
   - Assert: `result.insufficient_data is True`
   - Assert: `result.days_analyzed == 4`

3. **`test_exactly_min_days_produces_result`**
   - Input: `create_readings(n_days=5, glucose_value=110.0)`
   - Assert: `result.insufficient_data is False`
   - Assert: `result.days_analyzed == 5`
   - Note: Uniform glucose across all days means SD=0 for all buckets → baselines
     will be empty after the `bucket_std > 0` filter → `total_anomalies == 0`.
     This is correct behavior — assert `result.total_anomalies == 0`.

4. **`test_anomaly_detection_result_is_frozen`**
   - Create `AnomalyDetectionResult(insufficient_data=True)`
   - `with pytest.raises(Exception): result.total_anomalies = 5`

5. **`test_weekly_summary_is_frozen`**
   - Create a `WeeklySummary` with valid required fields
   - `with pytest.raises(Exception): summary.total_anomalies = 99`

6. **`test_pisa_artifacts_filtered_count`**
   - Build a set of readings that includes a PISA-signature drop/recovery pattern:
     create 10 days of normal readings (glucose=100), then on day 1 insert 3
     readings that drop to 60 mg/dL (40% drop from 100) and then recover back
     to 95 within 30 minutes.
   - Call `analyze_anomalies(readings)`.
   - Assert `result.pisa_artifacts_filtered >= 1` (at least the drop readings are filtered).

   Implementation hint for creating PISA readings:
   ```python
   from datetime import datetime, timedelta
   base = datetime(2024, 1, 8, 2, 0)  # 2am on day 1
   pisa_readings = [
       CGMReading(timestamp=base, glucose_mg_dl=100.0, source="test"),
       CGMReading(timestamp=base + timedelta(minutes=5), glucose_mg_dl=60.0, source="test"),
       CGMReading(timestamp=base + timedelta(minutes=10), glucose_mg_dl=58.0, source="test"),
       CGMReading(timestamp=base + timedelta(minutes=30), glucose_mg_dl=98.0, source="test"),
   ]
   ```
   Mix `pisa_readings` with normal readings from `create_readings(n_days=10)`.

7. **`test_classify_severity_thresholds`**
   - Import `_classify_severity` from `cgm_insights.analytics.anomaly_detection`
   - Assert `_classify_severity(1.9) is None`
   - Assert `_classify_severity(2.0).value == "mild"`
   - Assert `_classify_severity(2.99).value == "mild"`
   - Assert `_classify_severity(3.0).value == "moderate"`
