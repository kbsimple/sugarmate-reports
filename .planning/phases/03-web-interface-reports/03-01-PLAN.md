## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Upload -> Server | Untrusted file input crosses trust boundary |
| Server -> Core Library | Validated file path passed internally |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | File upload | mitigate | Validate file extension, MIME type, and size limits |
| T-03-02 | Denial of Service | File upload | mitigate | Limit file size to 10MB, limit uploads per minute per IP |
| T-03-03 | Information Disclosure | Error messages | mitigate | Generic error messages to user, detailed errors only in logs |
| T-03-04 | Spoofing | Session IDs | mitigate | Use UUID v4 for session IDs, cryptographically random |
</threat_model>
